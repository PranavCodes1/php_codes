UNIT 1: Introduction to Web Technologies
1.1 Qualities of a Good Website
A good website is one that provides useful information and a good experience to its users.

Qualities of a good website:
1. Simple Design: Website should have a clean, attractive and easy-to-understand design.
2. Easy Navigation: Users should easily find the required information.
3. Fast Loading: Website pages should load quickly.
4. Responsive Design: Website should work properly on mobile, tablet and desktop.
5. Good Content: Information should be accurate, useful and updated.
6. Security: Website should protect user data using security techniques like HTTPS.
7. Browser Compatibility: Website should work properly on different browsers.
8. SEO Friendly: Website should be designed to appear in search engine results.
9. Accessibility: Website should be usable by people with different abilities.
10. Regular Maintenance: Website should be updated and checked regularly.
Conclusion: A good website should be attractive, user-friendly, secure, fast and informative.
1.2 Web Client-Server and Its Communication
Web Client
1. A client is a device or software that requests services from a server.
2. A web browser acts as a client.
3. Examples: Google Chrome, Firefox and Microsoft Edge.
4. It sends HTTP requests to the web server.
5. It displays the received web pages to users.
Web Server
1. A web server is a computer or software that stores and delivers website content.
2. It receives requests from clients.
3. It processes requests and sends responses.
4. Examples: Apache, Nginx and Microsoft IIS.
Client-Server Communication
The client and server communicate using the HTTP/HTTPS protocol.

Steps of communication:
1. User enters a website URL in the browser.
2. Browser finds the IP address of the server using DNS.
3. Client establishes a connection with the server.
4. Browser sends an HTTP request.
5. Server processes the request.
6. Server sends an HTTP response.
7. Browser displays the requested webpage.
Diagram to remember:

Client (Browser) → HTTP Request → Web Server

Client (Browser) ← HTTP Response ← Web Server
1.3 HTTP Request Message and HTTP Response Message
A) HTTP Request Message
Definition: An HTTP request message is a message sent by a client to a web server to request a resource or service.

Main components:
1. Request Line: Contains HTTP method, URL and HTTP version.
2. Headers: Provide additional information about the request.
3. Blank Line: Separates headers from the message body.
4. Message Body: Contains data sent to the server, mainly with POST and PUT requests.
Example:
GET /index.php HTTP/1.1
Host: www.example.com
User-Agent: Chrome


Common HTTP Methods:
- GET – Retrieves data from the server.
- POST – Sends data to the server.
- PUT – Updates or replaces a resource.
- DELETE – Deletes a resource.
- HEAD – Retrieves only response headers.
B) HTTP Response Message
Definition: An HTTP response message is a message sent by the web server to the client after processing the request.

Main components:
1. Status Line: Contains HTTP version, status code and status message.
2. Headers: Provide information about the response.
3. Blank Line: Separates headers from the response body.
4. Message Body: Contains the requested webpage or data.
Example:
HTTP/1.1 200 OK
Content-Type: text/html

<html>
<body>
<h1>Welcome</h1>
</body>
</html>

Common HTTP Status Codes
Status Code	Meaning
200	OK – Request successful
301	Moved Permanently
400	Bad Request
401	Unauthorized
403	Forbidden
404	Not Found
500	Internal Server Error
503	Service Unavailable


1.4 Types of Websites (Static and Dynamic Websites)
Websites are mainly classified into two types:
A) Static Website
Definition: A static website displays fixed content to users. Its content remains the same unless manually changed by the developer.

Features:
1. Content is fixed.
2. Mainly developed using HTML and CSS.
3. Does not require server-side processing.
4. Loads faster.
5. Easy to develop and maintain.
6. Less expensive to host.
7. Suitable for small websites.
Examples: Portfolio websites, simple informational websites.
B) Dynamic Website
Definition: A dynamic website displays different content based on user input, database information or other conditions.

Features:
1. Content can change dynamically.
2. Uses server-side languages like PHP and Python.
3. Can connect with databases.
4. Supports user interaction.
5. Requires server-side processing.
6. More complex to develop.
7. Suitable for large and interactive websites.
Examples: Facebook, Amazon, online banking websites.

| Static Website | Dynamic Website |
|---|---|
| Content remains fixed. | Content changes dynamically. |
| Mainly uses HTML and CSS. | Uses PHP, Python and databases. |
| No server-side processing required. | Server-side processing is generally required. |
| Faster loading. | May require more processing time. |
| Easy to develop. | Comparatively complex. |
| Less interactive. | More interactive. |
| Example: Portfolio. | Example: E-commerce website. |



UNIT 2: Introduction to PHP
2.1 Lexical Structure
Definition: Lexical structure refers to the basic rules and elements used to write a PHP program.

Important elements:
1. PHP Tags: PHP code is written inside <?php and ?> tags.
<?php
echo "Hello World";
?>

Whitespace: Spaces, tabs and newlines are generally ignored by PHP.

Comments: Comments are used to explain the code and are ignored during execution.

Identifiers: Names given to variables, functions and classes.

Keywords: Reserved words having special meanings in PHP, such as if, else, while and function.

Variables: Variables are used to store data and always start with $.

Operators: Symbols used to perform operations, such as +, -, * and /.

Statements: Instructions written in a PHP program. Statements usually end with a semicolon (;).

2.2 Data Types
Definition: Data types specify the type of value that a variable can store.

PHP supports the following data types:
1. Integer: Stores whole numbers.
   $age = 20;
2. Float (Double): Stores decimal numbers.
   $price = 99.50;
3. String: Stores a sequence of characters.
   $name = "Pranav";
4. Boolean: Stores either TRUE or FALSE.
   $is_valid = true;
5. Array: Stores multiple values in a single variable.
   $colors = array("Red", "Blue", "Green");
6. Object: Stores data and functions together using a class.
7. NULL: Represents a variable with no value.
   $x = NULL;
8. Resource: Stores a reference to an external resource, such as an opened file.
2.3 Variables, Operators and Flow Control Statements
A) Variables
Definition: A variable is a named memory location used to store data.

Rules for declaring variables in PHP:
1. Every variable starts with $.
2. A variable name must start with a letter or underscore.
3. A variable name cannot start with a number.
4. Variable names are case-sensitive.
5. Variable names cannot contain spaces.
6. PHP does not require explicit data type declaration.
Example:
<?php
$name = "Pranav";
$age = 20;
echo $name;
echo $age;
?>

B) Operators
Definition: Operators are symbols used to perform operations on variables and values.

Types of operators:
1. Arithmetic Operators: Used for mathematical operations.
   +, -, *, /, %, **
2. Assignment Operators: Used to assign values.
   =, +=, -=, *=, /=
3. Comparison Operators: Used to compare two values.
   ==, ===, !=, >, <, >=, <=
4. Logical Operators: Used to combine conditions.
   &&, ||, !
5. Increment/Decrement Operators: Used to increase or decrease values.
   ++, --
6. String Operators: Used to join strings.
   . and .=
7. Conditional Operator: Used to write short conditional expressions.
   ?:
C) Flow Control Statements
Definition: Flow control statements control the order of execution of program statements.

Types:
1. if Statement: Executes code when a condition is TRUE.
   if ($age >= 18) {
       echo "Adult";
   }
2. if-else Statement: Executes one block if the condition is TRUE and another if FALSE.
3. if-elseif-else Statement: Checks multiple conditions.
4. switch Statement: Selects one block from multiple choices.
5. while Loop: Repeats statements while a condition is TRUE.
6. do-while Loop: Executes the statements at least once before checking the condition.
7. for Loop: Repeats statements a specified number of times.
8. foreach Loop: Used to traverse arrays.
2.4 Including Code – require and include
Definition: PHP provides include and require statements to insert the contents of one PHP file into another PHP file.
A) include
1. Used to include one PHP file inside another.
2. If the file is missing, PHP generates a warning.
3. The program continues executing.
4. Useful for including optional files.
Syntax:
include "header.php";

B) require
1. Used to include an external PHP file.
2. If the file is missing, PHP generates an error.
3. Program execution stops.
4. Useful for including important files.
Syntax:
require "config.php";

Difference Between include and require
| include | require |
|---|---|
| Generates a warning if file is missing. | Generates an error if file is missing. |
| Program continues executing. | Program stops executing. |
| Used for optional files. | Used for important files. |

2.5 Comments
Definition: Comments are statements written in a program to explain the code. They are ignored by the PHP interpreter.

Types of comments in PHP:
1. Single-line comment using //
   // This is a comment
2. Single-line comment using #
   # This is also a comment
3. Multi-line comment using /* */
   /*
   This is a
   multi-line comment
   */




UNIT 3: Function and String
This unit is important because it contains several programming concepts.
3.1 Defining and Calling a Function
Definition: A function is a block of code that performs a specific task. It can be reused whenever required.
Defining a Function
A function is defined using the function keyword.

Syntax:
function functionName() {
    // Statements
}

Calling a Function
A function is called by writing its name followed by parentheses.

Example:
<?php
function greet() {
    echo "Hello World";
}

greet();
?>

Advantages of functions:
1. Code reusability.
2. Reduces code repetition.
3. Makes programs easier to understand.
4. Simplifies debugging.
5. Improves program organization.
3.2 Variable Scope – Global Variables and Static Variables
Definition: Variable scope determines where a variable can be accessed in a PHP program.
A) Global Variables
1. Variables declared outside a function are called global variables.
2. They cannot be directly accessed inside a function.
3. The global keyword is used to access them inside a function.
Example:
<?php
$x = 10;

function display() {
    global $x;
    echo $x;
}

display();
?>

B) Static Variables
1. Static variables are declared using the static keyword.
2. They retain their values between function calls.
3. They are initialized only once.
4. Their scope is limited to the function in which they are declared.
Example:
<?php
function countValue() {
    static $count = 0;
    $count++;
    echo $count;
}

countValue();
countValue();
countValue();
?>

Output:
123

3.3 Function Parameters
Definition: Function parameters are variables used to pass values to a function.
A) Pass by Value
1. A copy of the variable is passed to the function.
2. Changes made inside the function do not affect the original variable.
Example:
<?php
function add($x) {
    $x = $x + 10;
}

$a = 5;
add($a);
echo $a;
?>

Output: 5
B) Pass by Reference
1. The actual variable is passed to the function.
2. Changes made inside the function affect the original variable.
3. The & symbol is used.
Example:
<?php
function add(&$x) {
    $x = $x + 10;
}

$a = 5;
add($a);
echo $a;
?>

Output: 15

Difference Between Pass by Value and Pass by Reference

| Pass by Value | Pass by Reference |
|---|---|
| Copy of variable is passed. | Reference to variable is passed. |
| Original value remains unchanged. | Original value can be changed. |
| Does not use `&`. | Uses `&` symbol. |

C) Default Parameters
1. A parameter is assigned a default value.
2. If no argument is passed, the default value is used.
3. It makes function calls easier.
Example:
function greet($name = "Guest") {
    echo "Hello " . $name;
}

greet();

Output: Hello Guest
D) Variable Parameters
1. A function can accept a variable number of arguments.
2. PHP uses the ... operator for variable-length arguments.
3. It is also called a variadic function.
Example:
function sum(...$numbers) {
    return array_sum($numbers);
}

echo sum(10, 20, 30);

Output: 60
E) Missing Parameters
1. Missing parameters occur when required arguments are not supplied during a function call.
2. If a required argument is missing, PHP generally generates an ArgumentCountError.
3. Default parameters can be used to avoid missing-argument errors.
Example:
function add($a, $b) {
    echo $a + $b;
}

add(10);

This produces an argument count error because the second required argument is missing.
3.4 Variable Function and Anonymous Function
A) Variable Function
1. A variable function is a function called using a variable containing its name.
2. The variable stores the function name as a string.
3. Parentheses are used to call the function through the variable.
Example:
<?php
function hello() {
    echo "Hello";
}

$fun = "hello";
$fun();
?>

Output: Hello
B) Anonymous Function
1. An anonymous function is a function without a name.
2. It is also called a closure.
3. It can be assigned to a variable.
4. It is commonly used as a callback function.
Example:
<?php
$greet = function() {
    echo "Hello World";
};

$greet();
?>

Output: Hello World

Difference Between Variable and Anonymous Functions

| Variable Function | Anonymous Function |
|---|---|
| Calls a named function using a variable. | Function does not have a name. |
| Variable stores the function name. | Variable stores the function itself. |
| Uses an existing named function. | Defines a function without a name. |

3.5 Types of Strings in PHP
Definition: A string is a sequence of characters enclosed within quotation marks.

PHP supports four main string syntaxes:
1. Single Quoted String
1. Enclosed within single quotes ' '.
2. Variables are not evaluated.
3. Most escape sequences are not interpreted.
$name = 'Pranav';
echo 'Hello $name';

Output: Hello $name
2. Double Quoted String
1. Enclosed within double quotes " ".
2. Variables are evaluated.
3. Escape sequences like \n and \t are supported.
$name = "Pranav";
echo "Hello $name";

Output: Hello Pranav
3. Heredoc
1. Used to define multi-line strings.
2. Similar to double-quoted strings.
3. Variables are evaluated.
$text = <<<EOT
Hello
Welcome to PHP
EOT;

echo $text;

4. Nowdoc
1. Used to define multi-line strings.
2. Similar to single-quoted strings.
3. Variables are not evaluated.
4. Uses single quotes around the ending identifier.
$text = <<<'EOT'
Hello $name
EOT;

echo $text;

3.6 Printing Strings
PHP provides different methods to display strings.
1. echo
1. Used to display one or more strings.
2. It does not return a value.
3. It is a language construct.
echo "Hello World";

2. print
1. Used to display a string.
2. It returns the value 1.
3. It accepts only one argument.
print "Hello World";

3. printf()
1. Used to display formatted strings.
2. Supports format specifiers.
3. Commonly used for numbers and variables.
$name = "Pranav";
printf("Hello %s", $name);

4. print_r()
1. Used to display human-readable information about variables.
2. Commonly used for displaying arrays.
$arr = array(10, 20, 30);
print_r($arr);

5. var_dump()
1. Displays variable information.
2. Shows both data type and value.
$x = 10;
var_dump($x);

3.7 Comparing Strings
PHP provides different functions to compare strings.
1. strcmp()
- Compares two strings case-sensitively.
- Returns 0 if both strings are equal.
- Returns a negative value if the first string is smaller.
- Returns a positive value if the first string is greater.
echo strcmp("Hello", "Hello");

Output: 0
2. strcasecmp()
- Compares two strings without considering uppercase and lowercase differences.
echo strcasecmp("HELLO", "hello");

Output: 0
3. strnatcmp()
- Compares strings using natural ordering.
- Useful for comparing strings containing numbers.
4. strncmp()
- Compares the first specified number of characters of two strings.
5. Similar_text()
- Calculates the number of matching characters between two strings.
3.8 Manipulating Strings
Definition: String manipulation means performing operations such as joining, modifying, searching and replacing characters in a string.

Important PHP string functions:
Function	Purpose
| Function | Purpose |
|---|---|
| strlen() | Returns the length of a string. |
| str_word_count() | Counts the number of words. |
| strtoupper() | Converts string to uppercase. |
| strtolower() | Converts string to lowercase. |
| ucfirst() | Converts first character to uppercase. |
| ucwords() | Converts the first character of each word to uppercase. |
| strrev() | Reverses a string. |
| strpos() | Finds the position of a substring. |
| str_replace() | Replaces text in a string. |
| substr() | Extracts a part of a string. |
| trim() | Removes whitespace from both ends. |
| ltrim() | Removes whitespace from the left side. |
| rtrim() | Removes whitespace from the right side. |
| explode() | Converts a string into an array. |
| implode() | Converts an array into a string. |

Example:
<?php
$str = "hello world";

echo strtoupper($str);
echo strlen($str);
echo strrev($str);
?>

3.9 Regular Expressions
Definition: A regular expression is a pattern used to search, match and manipulate text.

PHP supports regular expressions through functions such as preg_match(), preg_replace() and preg_split().
Common Regular Expression Symbols
Symbol	Meaning
.	Matches any character except newline.
^	Matches the beginning of a string.
$	Matches the end of a string.
*	Matches zero or more occurrences.
+	Matches one or more occurrences.
?	Matches zero or one occurrence.
[abc]	Matches a, b or c.
[0-9]	Matches any digit.
[a-z]	Matches lowercase letters.
[A-Z]	Matches uppercase letters.
\d	Matches a digit.
\w	Matches a word character.


Important PHP Regular Expression Functions
1. preg_match()
- Checks whether a pattern exists in a string.
- Returns 1 if matched and 0 if not matched.
preg_match("/hello/", "hello world");

2. preg_replace()
- Searches for a pattern and replaces it with another string.
echo preg_replace("/hello/", "Hi", "hello world");

Output: Hi world

3. preg_split()
- Splits a string using a regular expression.
